# 独立反例边界检查

状态：passed；20 项精确有理数检查。仅 CPU，无远端访问或产品修改。

完整缓存覆盖且总容量等于16GiB时，唯一字节没有复制空间，S1必须输出8GiB，故全分片下界4/3秒。整块贪心布局8秒，交叉4/3秒；分片最优布局不唯一，a∈[0,4/3]GiB均最优。

独立0.1GiB/s后备给P供给字节，可把交叉布局时间改成80/61秒，严格小于4/3。慢路径不等于无收益。合法S1→S0中继可使原贪心布局≤7/3秒，破坏8秒评价，但仍服从S1唯一字节egress cut。

m=3/4的关键rank平台：独立1GiB/s底本路径下，≤2个cache增量不能降低max，全部cache将8秒改为4秒。若底本只有共享1GiB/s注入，目标变成剩余总字节，单cache立即有收益，平台反例不成立。每rank独立8GiB/s缓存服务即可取得4秒，不需要零时间缓存。

这些例子只反驳指定的严格正增益/固定顺序规则。assignment、平衡填充、词典序或允许零增益推进可以解决；不证明通用贪心失败、MILP必要或理论新颖。
