### 原证据中被遗漏的transport差异

原rank0/2实际GPU9000 distance4≤4，channel `/GDRDMA`；rank1/3 GPU36000 distance7>4，GPU-specific Disabled，32条send/recv都没有GDR后缀。因此旧“直接GPU通信”只描述GPU tensor接口，B并非实际GDR。HCA能力探测Disabled行与随后GPU-specific Enabled、以及GDRCopy关闭是不同开关，不能混读。

两端实际库RCCL2.22.3-HEAD19c80f7，载入builtin-508-topo-input-tj-default.xml。forensics只读保存部署库/plugin/XML SHA；文件给GPU1 NUMA1/CPU16–31，而sysfs为NUMA3/CPU48–63；shca1实际PCI71，被XML放在GPU1 PCI31分支。mask ffff0000确为16–31，不是压缩编号。参考RCCL源码解释初始化线程设置affinity后作host分配再恢复，不等于整个进程/proxy永久绑定；精确vendor源码未取得，host-backed缓冲页位置未实测。
